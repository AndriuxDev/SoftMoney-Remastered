# Welcome to SoftMoney Remastered!
A gentle, open-source remaster of [**SoftMoney**](https://paper-pepper.itch.io/softmoney), built in **Ren'Py** — keeping the same story, visuals, and wholesome Harvey, now with smoother UI and expanded language support.

---

## 💬 Developer Note

> Yes, I know **DDLC + Andriux After Story** was a mistake — and this is my way to apologize to the **DDLC** devs/fans and the **Ren’Py** devs/fans.
> This is **not a DDLC mod**, let alone a 'DDLC + Andriux After Story Done Right' — it’s a wholesome remaster of a money clicker-style visual novel made with full respect and love for both communities. ❤️

---

## 🕹️ Overview

**SoftMoney Remastered** is a community-driven update of the original *SoftMoney* by **paper pepper**.  
It preserves the cozy, comforting tone of the original while refining the user experience and broadening accessibility.

### ✨ What’s New
- Refined, modernized **UI/UX**
- Added **new translations** (beyond English and Russian)
- Improved **dialogue flow** and **readability**
- Minor **bug fixes** and script clean-up
- Same **story, visuals, and heart** — just smoother overall!
- **Achievements** to keep track of progress (thanks Feniks!)

## 🚀 Installation

1. Go to the [**Releases**](../../releases) tab.  
2. Download the latest version for your platform.  
3. Extract the ZIP file.  
4. Run:
   - `SoftMoneyRemastered.exe` on **Windows**
   - `SoftMoneyRemastered.sh` on **Linux/Mac**

You can also open the project in Ren'Py to explore or build your own version.
